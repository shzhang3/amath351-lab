What does each term mean?

Displacement x is measured from equilibrium. Mass m is positive, spring stiffness k is positive, and damping c is nonnegative. The spring force −k x points toward equilibrium. The damping force −c x′ opposes the velocity.

Newton’s law gives m x″ = −c x′ −k x. After release, no external driving force acts. This is free motion, described by a homogeneous equation.

How do the characteristic roots explain the motion?

m r² + c r + k = 0   ccritical = 2 √(m k)

  • c = 0: purely imaginary roots. Oscillation has constant amplitude.
  • 0 < c < ccritical: complex roots with negative real part. Oscillation decays.
  • c = ccritical: one repeated negative root. The solution has the form (A + B t)ert.
  • c > ccritical: two distinct negative roots. The solution is a sum of decaying exponentials.

Critical and overdamped motion do not oscillate repeatedly. With some initial velocities they can cross equilibrium once. For the default release from rest, both remain on the initial side; the critical curve returns faster than the overdamped comparison.

For no damping, the period is T = 2π √(m/k). Increasing m makes oscillation slower; increasing k makes it faster. With positive damping, the amplitude shrinks, so the full motion is not periodic.

A short classroom exploration
  1. Reset. Play the undamped motion. Increase m, then increase k. Predict each change before playing again.
  2. Keep m = 1 kg, k = 4 N/m, x(0) = 1 m, and x′(0) = 0. Compare the four damping buttons.
  3. Turn on the comparison. Which curves oscillate? Does increasing resistance beyond critical make the return faster?
