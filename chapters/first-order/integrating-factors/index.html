What does an integrating factor change?

xy′ − 3y = x³,   y(1) = 10.

Read the slope field, reveal the solution through the initial point, then multiply by the integrating factor. Move along the curve to connect each tangent to the differential equation.

A solution before and after multiplying by x⁻³

The lecture uses y(1) = 10. Changing this value selects another solution of the same equation.

We work on I = (0, ∞), the interval containing x = 1 on which the standard-form coefficients are continuous.

Original equation

y′ = 3y/x + x²

After the integrating factor

z = y/x³,   z′ = 1/x

Slope field Initial point Exact solution Current tangent

1 · Standard form

y′ − (3/x)y = x²

Divide by x on x > 0.

2 · Multiply

q(x) = e−3 ln x = x⁻³

(x⁻³y)′ = 1/x

3 · Integrate and use the initial value

y/x³ = ln x + C

Why do we use x > 0 even though the curve approaches the origin?

In standard form, P(x) = −3/x and Q(x) = x². Both are continuous on (0, ∞), which contains the initial x = 1. The linear existence and uniqueness theorem gives one solution on that entire interval, not just near x = 1.

For every finite C, x³(ln x + C) → 0 as x → 0⁺. A finite limit does not make the standard-form equation defined at zero. The open circle marks a limit, not an included point of the displayed solution.

The original equation xy′ − 3y = x³ degenerates at x = 0. It can admit differentiable continuations through the origin, but this theorem does not determine them uniquely. For example, y = x³(ln|x| + C₋) on x < 0, y(0) = 0, and the chosen positive-side solution fit together for any C₋. The plots here stay on x > 0.

What changed in the second field?

Multiplying by x⁻³ packages the two terms y′ − 3y/x into the derivative of one quantity, z = x⁻³y. The new slope z′ = 1/x depends only on x: every point in the same vertical column has the same slope. Different initial values translate the z curves vertically.

The transformed graph is z = ln x + C plotted against x, so it is a logarithmic curve. The two graphs use different vertical scales. Both use exact formulas, and the moving points have the same x coordinate.
