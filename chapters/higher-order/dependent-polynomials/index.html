Section 3.2 · Linear dependence and Wronskian volume

Three functions, zero volume

f₁ = 2x   f₂ = 3x²   f₃ = 5x − 8x²

At x = 0, turn each function’s value, slope, and second derivative into a vector. The three arrows have different directions, but they all lie in one plane. View that plane from the side to see why the volume is zero.

vᵢ = (fᵢ(0), fᵢ′(0), fᵢ″(0))

Three initial-data arrows

Evaluate at x = 0

Coordinates are value, slope, and second derivative, in that order. These vectors form the columns of the Wronskian.

Does the third arrow add a new direction?

v₃ = (5/2) v₁ − (8/3) v₂

The dashed path first follows v₁ to (0, 5, 0), then moves opposite to v₂ to reach (0, 5, −16). It stays in the same plane throughout.

The same constants relate the functions for every x:

f₃ = (5/2) f₁ − (8/3) f₂.

Three vectors are (0, 2, 0), (0, 0, 6), and (0, 5, minus 16). They all have first coordinate zero and lie in one plane. The first two span a base of area 12, but the third has zero perpendicular height, so the three-dimensional volume is zero. Camera buttons and sliders change only the projection. A checkbox shows the third vector as a linear combination of the first two.

How does this connect to linear independence?

Two of these vectors are independent: v₁ and v₂ are not parallel. Adding v₃ gives no direction outside their plane, so the set of three vectors is dependent. It has nonzero area within its plane, but zero three-dimensional volume.

All three polynomials solve the same regular third-order homogeneous equation y‴ = 0 on ℝ. Their constant function relation directly proves dependence on ℝ. In particular, every combination of this chosen set has y(0) = 0, so it cannot represent a solution with y(0) = 1.

The Wronskian is W(0) = 0. For solutions of the same regular homogeneous linear equation, a zero Wronskian at one point detects dependence. For arbitrary functions, a zero Wronskian at one point alone is not enough.
